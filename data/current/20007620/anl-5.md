## Parameter für die Erhebung der Daten von neuen Marktteilnehmern

| Parameter | Anmerkungen |
| --- | --- |
| Bezeichnung des Produkts bzw. der Produkte |  |
| NACE–Code der Tätigkeit |  |
| PRODCOM-Codes des Produkts bzw. der Produkte |  |
| Installierte Anfangskapazität vor der wesentlichen Erweiterung | Nur für Unteranlagen, für die eine wesentliche Kapazitätserweiterung mitgeteilt wird. |
| Zusätzliche Kapazität (im Fall einer wesentlichen Erweiterung) | Nur für Unteranlagen, für die eine wesentliche Kapazitätserweiterung mitgeteilt wird. |

Juni 2011 die Genehmigung zur Emission von Treibhausgasen erteilt wurde oder die eine Tätigkeit ausüben, die gemäß § 2 Abs. 4 oder 5 EZG 2011 erstmals in den Geltungsbereich des EZG 2011 einbezogen wurde. Ausgedrückt für Unteranlagen, für die ein Produkt-Referenzwert gilt, in der jeweiligen, in Anhang 1 genannten Einheit, Unteranlagen, für die ein Wärme-Referenzwert gilt, in Terajoule messbarer Wärme, die für die Herstellung von Produkten oder die Erzeugung von mechanischer Energie außer Strom- oder Wärmeerzeugung oder Kühlung innerhalb der Anlagengrenzen pro Jahr verbraucht wird, Unteranlagen, für die ein Brennstoff-Referenzwert gilt, als Terajoule Brennstoff-Input pro Jahr, Prozessemissionen als pro Jahr emittierte Tonnen Kohlenstoffdioxid-Äquivalent. |
| Relevanter Kapazitätsauslastungsfaktor (RKAF) | Für Unteranlagen, die nicht unter einen Produkt-Referenzwert fallen. |
