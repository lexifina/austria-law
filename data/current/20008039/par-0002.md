### Immissionsschwellenwerte für Fluglärm

§ 2. Für die Beurteilung von durch das Vorhaben bedingter unzumutbarer Belästigung der Nachbarn durch Fluglärm gelten folgende Immissionsschwellenwerte:

| 1\. | Tag: | Antragstellung bis zum Ablauf des 31. Dezember 2014: | L<sub>Aeq</sub> <sub>Tag</sub> | = | 62 dB(A) Außenpegel, |
| --- | --- | --- | --- | --- | --- |
|  |  | Antragstellung ab 1. Jänner 2015: | L<sub>Aeq</sub> <sub>Tag</sub> | = | 60 dB (A) Außenpegel |
| 2\. | Nacht: | Antragstellung bis zum Ablauf des 31. Dezember 2014: | L<sub>Aeq</sub> <sub>Nacht</sub> | = | 52 dB(A) Außenpegel |
|  |  |  | L<sub>Amax</sub> | = | 6-mal 68 dB(A) Außenpegel |
|  |  | Antragstellung ab 1. Jänner 2015 | L<sub>Aeq</sub> <sub>Nacht</sub> | = | 50 dB(A) Außenpegel |
|  |  |  | L<sub>Amax</sub> | = | 6-mal 68 dB(A) Außenpegel. |
